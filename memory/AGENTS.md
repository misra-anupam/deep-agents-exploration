# Desk conventions (house memory)

This file is loaded into every session. Keep it short and durable.

## Coverage and style
- Notes are conservative and sourced. A number without a citation does not go in.
- Stance vocabulary: Positive / Neutral / Negative. Never "buy" or "sell".
- Materiality: treat a change under 2% of revenue as noise unless the filing calls it out.

## Memory layout
- `/memories/<TICKER>/thesis.md` — current thesis for a ticker. Read it BEFORE analysing a
  new period, and say explicitly what changed since. Update only via `update_thesis`.
- `/memories/<TICKER>/history/<PERIOD>.md` — prior theses, one per period (written by the tool).
- `/reports/` — published notes.
